# Versions

## 0.3.0 bêta pour Mac — 19 novembre 2026

- **Première version Mac.** Le même panneau que sur Windows : familles, lecteur avec forme d'onde, temps fort,
  effets, kits, tempo, sons proches, licences par pack.
- **Fenêtre libre** : le panneau ne se colle pas encore au bord de Resolve, il garde la place où tu le poses.
- **Raccourcis dans Resolve** en Cmd+Option+Maj (Ctrl+Alt+Maj sur Windows).
- **Installeur pour Mac** : un double-clic, le mot de passe de ta session, et il prend le module de Resolve
  installé sur ton Mac.
- Depuis la dernière bêta Windows (0.2.0) : un écran d'accueil à chaque lancement, un menu de réglages, des écrans
  vides qui guident, **Normaliser** et le volume dans les effets, tes propres préréglages d'effets, la grille des
  temps sur les musiques, tes propres synonymes pour la recherche, la copie d'un kit dans le dossier d'un projet
  avec ses crédits, et un démarrage qui ne bloque plus le panneau.
